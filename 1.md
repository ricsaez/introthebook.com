To describe our language, we need to refer to things without choosing particular ones. We use **placeholders** for this.

For example, consider arithmetic. We can use `a` and `b` as placeholders for numbers:

    a + b

Replacing `a` with `2` and `b` with `3` gives:

    2 + 3

We can now begin describing our own language.

When we express something, we call what we express an **expression**.

To refer to an expression without choosing a particular one, we use the placeholder:

    e
