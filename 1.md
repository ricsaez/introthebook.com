To describe our language, we need to refer to things without choosing particular ones. We use **placeholders** for this.

For example, consider arithmetic. We can use `a` and `b` as placeholders for numbers:

    a + b

Replacing `a` with `2` and `b` with `3` gives:

    2 + 3

We can now begin describing our own language.

When we express something, we call what we express an **expression**.

To refer to an expression without choosing a particular one, we use the placeholder:

    e

We begin with **values**. A value is an expression, and we use `v` as a placeholder for one.

Values belong to **types**. For our first types, we list the possible values. Using `T` for a type and `v`, `v'`, … for its values, we write:

    T = v | v' | …

The `|` separates the possibilities. For example:

    Bool = false | true

This introduces a type, `Bool`, with two values: `false` and `true`. Each is also an expression.

To say that an expression `e` has type `T`, we write:

    e : T

For example:

    true : Bool

We can give an expression a name, so we can refer to it without repeating it. Using `x` as a placeholder for a name, we write:

    x = e

For example:

    answer = true

We can now use `answer` to refer to `true`.

A **function** gives an expression for each possible input. We describe it through **cases**. Each case says which expression to use for a particular input value:

    (v) ↦ e

This reads “given `v`, use `e`.”

Using `f` as a placeholder for the function’s name, we separate its cases with `|`:

    f = (v) ↦ e | …

For example:

    not = (true) ↦ false | (false) ↦ true

Given `true`, this function gives `false`; given `false`, it gives `true`.

Giving a function an input is a **call**. We write the input in parentheses after the function’s name:

    f(v)

The call becomes the expression given by its matching case. We call this a **step**, and write it using `>>`:

    f(v) >> e

For example:

    not(true) >> false

Both sides are expressions. The call `not(true)` reaches the value `false` in one step.

A function’s type describes its inputs and outputs. Using `T` for the input type and `T'` for the output type, we write:

    f : T → T'

For example:

    not : Bool → Bool

This says that `not` takes a `Bool` and gives back a `Bool`.
